## 🚀 Sobre Mim

Sou um desenvolvedor apaixonado por criar soluções que conectam o mundo físico ao digital. Meu portfólio reflete uma jornada versátil, variando desde **aplicações web robustas** (Full Stack) até projetos de **IoT (Internet das Coisas)** e desenvolvimento de jogos web.

Tenho experiência prática na construção de APIs, gerenciamento de sistemas e integração de hardware (ESP32) com software. Estou sempre em busca de novos desafios técnicos para aprimorar minhas habilidades em **JavaScript, TypeScript e C++**.
